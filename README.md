# IRCTC Premium Travel — UI Concept

A responsive React/Vite concept for a modern unified IRCTC-style booking experience.

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL printed by Vite.

## Included
- Dark cinematic hero with looping video background (remote video source)
- Animated booking tabs for Trains, Flights, Bus and Hotels
- From/To fields, swap button, date picker and quick date buttons
- Sample train cards, date strip, availability blocks and filter toggles
- Popular destination image cards, Vande Bharat promotional banner and offers carousel
- Responsive mobile layout and motion effects


## Prototype limitations
This is a front-end prototype. Train availability, fares, booking actions, offers, login, and other non-train travel modes are demo content; no tickets can be purchased. A live backend requires authorized rail data/booking API access, credentials, payment integration, secure passenger handling, and provider agreements. Do not use the sample availability for travel decisions.
